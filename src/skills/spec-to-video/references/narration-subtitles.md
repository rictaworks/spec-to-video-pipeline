# ナレーションと字幕

工程 P4（ナレーション合成と実尺計測）と P6（字幕生成と可読検査）で読み込みます。

## 目次

1. 合成の単位
2. 話者とエンジン
3. 実尺の計測と書き戻し
4. 尺整合の判定
5. 字幕の生成と可読規約

---

## 1. 合成の単位

**ナレーションはカット単位で合成します。** シーン全体を1本の音声にまとめません。アニメーションとの同期をカット単位で取るため、また特定カットの差し替え時に他カットを作り直さないためです。

- 台本台帳の `scenes[].cuts[]` が合成の単位です
- 合成結果は `cuts[].audio_path` に、実尺は `cuts[].measured_narration_sec` に記録します
- シーン全体の実尺は、そのシーンに属するカットの実尺の合計です

## 2. 話者とエンジン

- 既定の話者は**四国めたん（ノーマル）**です
- 動画設計書の `narration.speaker` に指定がある場合は、そちらを優先します
- エンジンは `narration.engine` から取得します
- ローカル TTS はネットワーク通信と資格情報を要しません。モデルと音声データは事前導入を前提とし、実行中に取得しません
- エンジンまたは音声データが利用できない場合、別のエンジンへ切り替えずに停止し、不足しているものを提示します

## 3. 実尺の計測と書き戻し

1. カットごとに音声を合成します
2. 合成した音声ファイルの長さを計測します。台本の文字数からの推定値を用いません
3. `cuts[].measured_narration_sec` と、シーンの `measured_narration_sec` を台本台帳へ書き戻します
4. 書き戻しに失敗した場合は停止します。計測値のない台帳で後続の工程へ進みません

## 4. 尺整合の判定

P5 で判定します。判定はシーン単位で行います。

| 条件 | 扱い |
|---|---|
| ナレーション実尺がシーン尺を超える | 停止します。文言の短縮または尺の延長を選択肢として提示します |
| ナレーション実尺がシーン尺を大きく下回る | 継続します。差分を実行レポートに記録します |

自動で文言を削る、あるいは自動で尺を延ばすことはしません。どちらも設計の変更にあたるためです。

## 5. 字幕の生成と可読規約

`scripts/build_subtitles` が台本台帳から `out/subtitles.srt` を生成します。

| 項目 | 規約 |
|---|---|
| 1行あたりの文字数 | 上限を設定ファイルで定めます |
| 行数 | 1つの字幕あたりの上限を設定ファイルで定めます |
| 表示時間 | 下限を設定ファイルで定めます。ナレーションの実尺に基づいて決めます |
| 文体 | ですます調で統一します |
| 文脈自立 | 各シーンの字幕が単体で状況を示す構造にします |

規約に反する字幕がある場合、生成せずに停止します。**規約を満たすよう自動で改行位置を変える、あるいは文言を削ることはしません。**
