# コンプライアンス検証と審査

工程 P13（機械検証）と P14（人間審査）で読み込みます。

## 目次

1. 機械検証の項目と判定
2. 意図的変化シーンの扱い
3. 人間が審査する項目
4. 検出結果の読み方
5. 参照する基準の記録

---

## 1. 機械検証の項目と判定

`scripts/analyze_frames` が実行し、結果を `out/frame_analysis.json` へ出力します。

| 項目 | 検査内容 | 判定 |
|---|---|---|
| 光感受性 | 隣接フレーム間の輝度差を計測し、輝度変化を伴う点滅の頻度を求めます。鮮やかな赤の点滅は別に計測します | 安全基準の上限を超える区間があれば不適合とします |
| 規則的パターン | 縞・渦巻き・同心円が画面の大部分を占める区間を検出します | 検出区間は人間審査へ回します |
| 不連続フレーム | シーン変化検出により、前後と不連続な短時間フレームを抽出します | 宣言区間を除いた検出は不適合とします |
| 出力規格 | 解像度・フレームレート・コーデック・音声形式を設計書の指定と照合します | 一致しない場合は不適合とします |
| グレースケール | 変換後に意味が失われないことを確認します | 判定は人間審査と併用します |

閾値は設定ファイルに置き、スクリプトに直書きしません。採用する基準とそのバージョンは 5 節に記録します。

## 2. 意図的変化シーンの扱い

演出として輝度や色を大きく変えるシーンは、機械検出では不連続として現れます。設計書の `intentional_luminance_change` が真であるシーンは、**宣言された区間を除外したうえで**不連続の判定を行います。

- 宣言のないシーンで検出された不連続は、除外しません
- 除外した区間は `out/frame_analysis.json` に記録し、実行レポートにも「除外した区間」として残します
- 光感受性の計測は、宣言の有無にかかわらず全区間で行います。宣言は不連続判定の除外にのみ用います

## 3. 人間が審査する項目

機械検証だけで合否を確定しません。以下は人間が判断します。

- 機械検出されたフレームの最終判断
- 表現内容（差別的表現・過度に刺激的な表現・誤解を招く表現）の審査
- 意図しない文字・ロゴ・実在人物の映り込みの最終確認
- 素材間の質感連続性（配色・明度・動きの速度）の通し再生による確認
- **テロップの判読性の確認。暗い実写カットと淡色の図解カットの双方で行います**
- **常設テロップ・章タイトル字幕が、図解の文言に重なっていないことの確認**

テロップが潰れる・背景に同化する・図解へ重なる、のいずれも書き出しは成功します。機械検証では検出されないため、人間審査でしか見つかりません。

## 4. 検出結果の読み方

`out/frame_analysis.json` は、項目ごとに検出区間を秒で保持します。差し戻し先は検出区間から決めます。

| 検出区間 | 想定原因 | 差し戻し先 |
|---|---|---|
| トランジション区間 | 遷移の設定・重なり | P11 |
| 字幕・オーバーレイ層 | 表示時間・配置・書式 | P11 |
| 単一素材の区間内 | 素材そのものの明滅・グリッチ・映り込み | P9 または P10 |
| 図解内の文言 | 誤字・文字の崩れ | P3 で文言を確定し直し、P10 |
| 全編にわたる規格不一致 | 出力設定 | P12 |
| シーン尺・字幕文言に起因 | 設計そのもの | P3（設計書の修正が必要です） |

再レンダリングで解消できる不適合に、再生成を選びません。

## 5. 参照する基準の記録

審査基準・そのバージョン・確認日は `docs/references.md` に記録します。基準が改訂された場合は、既存の検出条件との差分を確認してから閾値を更新します。
