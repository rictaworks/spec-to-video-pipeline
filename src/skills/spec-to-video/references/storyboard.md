# 絵コンテの読み取り

工程 P3（台本と文言の確定）と P7（カット割りと演出の選定）で読み込みます。絵コンテが存在しない案件では、この参照ファイルを読み込みません。

## 目次

1. 絵コンテの位置づけ
2. 読み取る項目と台帳への対応
3. 設計書との突き合わせ
4. 矛盾したときの扱い
5. 絵コンテが無い場合

---

## 1. 絵コンテの位置づけ

絵コンテは、動画設計書が定めた構成を、**カット単位の具体まで落とした資料**です。設計書に無い情報を持ちます。

| 設計書が定めるもの | 絵コンテが定めるもの |
|---|---|
| シーンの尺・カット数・映像内容の方針 | カットごとの確定文言、構図、カメラの動き、IN 点 |
| ナレーションの方針 | 読み上げる原稿そのもの |
| 字幕の方針 | 画面に出す字幕の文言 |

**形式は案件ごとに異なります。** HTML・Markdown・PDF・デザインツールの書き出しなど、体裁を前提にしません。設計書と同様、読み取りはエージェントの判断で行います。決まった見出しや表の形を探しにいきません。

## 2. 読み取る項目と台帳への対応

| 絵コンテの情報 | 反映先 |
|---|---|
| カット識別子 | 台本台帳 `scenes[].cuts[].cut_id` |
| カットの尺・IN 点 | 台本台帳 `scenes[].cuts[]`、および P7 のカット割り |
| ナレーション原稿 | 台本台帳 `scenes[].cuts[].narration_text` |
| 字幕文言 | 台本台帳 `scenes[].subtitle_lines[]` |
| 図解に入れる文言 | 台本台帳 `scenes[].figure_text[]` |
| 常設テロップの扱い | 台本台帳、および P7 の演出の選定 |
| 構図・カメラの動き・生成時の回避指定 | 素材台帳 `materials[].prompt`（`assets/prompt.template.md` に沿って組み立てます） |
| トランジションの指定 | P7 の演出の選定（`remotion-project.md` 6 節） |

絵コンテの作図（枠線や矩形で描かれた構図）は、**生成結果そのものではなく構図の指示**です。プロンプトの被写体・カメラワークの記述へ落とし、画像として素材に使いません。

## 3. 設計書との突き合わせ

絵コンテを読み取ったら、設計書側と次を照合します。

| 対象 | 判定 |
|---|---|
| カット数 | シーンごとに一致すること |
| カット識別子 | 設計書側にカット識別子がある場合、集合が一致すること |
| 尺 | カットごとに一致すること |
| 素材種別 | カットごとに一致すること |

一致しない場合は停止し、**どのカットがどう食い違うか**を示します。どちらが正かをこちらで決めません。

## 4. 矛盾したときの扱い

設計書と絵コンテで指示が食い違う場合、停止して確認を求めます。**新しい方・詳しい方を自動的に採らないでください。** 尋ね方は `assets/question.template.md` の「資料が矛盾している場合」に従い、両方の記述をそのまま並べて示します。

食い違いの例です。

- 設計書が「常設テロップは全編静止表示」と定め、絵コンテが「末尾で別の文言へ差し替える」としている
- 設計書が「カット間にトランジションを挟まない」と定め、絵コンテがカット境界の遷移を描いている
- 尺の合計が設計書の総尺と一致しない

いずれも、設計そのものの変更にあたります。確認の結果は、設計書か絵コンテのいずれかを一次情報として選び、選んだ根拠とともに実行レポートへ記録します。

## 5. 絵コンテが無い場合

絵コンテが無い案件では、P3 で台本と文言をこちらで起こし、P7 でカット割りと演出を選定します。絵コンテの不在は停止の理由になりません。設計書の記述だけで文言を確定できない場合に限り、停止して追記を求めます。
