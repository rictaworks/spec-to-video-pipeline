# 生成主体モードの手順

`production_mode` が `generative` の場合に、工程 P8〜P10 で読み込みます。Remotion 単独モードの場合はこのファイルを読み込みません。

## 目次

1. 工程の流れ
2. 起点画像の生成と採否
3. クリップの生成と採否
4. 図解画像の生成と採否
5. 生成記述の設計
6. 採否の基準

---

## 1. 工程の流れ

| 工程 | 内容 |
|---|---|
| P8 | 起点画像を生成し、採否を決めます |
| P9 | 採用した起点画像から image-to-video でクリップを生成し、採否を決めます |
| P10 | 静的な図解画像を生成し、採否を決めます |

いずれも `scripts/generate_asset` を唯一の窓口として実行します。**直前に承認ゲートがあり、承認なしでは生成を開始しません。**

## 2. 起点画像の生成と採否

**構図と被写体のリテイクは、この段階で完了させます。** クリップの生成は単価が高く、構図の作り直しを動画側で行うと課金が膨らみます。

1. カットごとに起点画像を生成します
2. 構図・被写体・配色を確認し、採否を決めます
3. 採用した画像の `material_id` を、クリップ側の `source_still_id` に記録します

## 3. クリップの生成と採否

1. 採用済みの起点画像を入力に、image-to-video で生成します
2. 許容クリップ長は動画設計書と実行環境から取得します。スキル側に埋め込みません
3. シーン尺が許容クリップ長の組合せで一致しない場合、超過分を生成し、余剰は合成側のトリムで吸収します
4. カット数は設計書の指定に一致させます

## 4. 図解画像の生成と採否

- 図解に入れる文言は、P3 で校正が完了している必要があります。**未校正の文言で生成しません**
- 文字の崩れが生じた場合、差し戻し先は P3（文言の確定）と P10（再生成）です

## 5. 生成記述の設計

`assets/prompt.template.md` に従い、次の要素で構成します。

| 要素 | 内容 |
|---|---|
| 被写体 | 何が映るか |
| 動き | 被写体とカメラのどちらがどう動くか |
| カメラワーク | 画角・寄り引き・移動 |
| 尺 | 秒数 |
| 回避指定 | 映してはならないもの |

モデル名を記述に含めません。記述はモデル非依存の表現に限定します。

## 6. 採否の基準

次のいずれかに該当する素材は採用しません。**加工して使い回すこともしません。**

- 実在の人物・ロゴ・他社著作物が映り込んでいる
- 意図しない文字が映り込んでいる
- 明滅・グリッチが含まれる
- 前後のカットと質感（配色・明度・動きの速度）が連続しない

採否と確認日は素材台帳の `review` に記録します。
