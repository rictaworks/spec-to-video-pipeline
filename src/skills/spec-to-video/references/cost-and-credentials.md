## 1. 前提ゲートの判定

P2 では次を確認します。いずれかを満たさない場合は停止し、不足を提示します。

| 対象 | 確認内容 |
|---|---|
| 実行環境 | 環境変数 `SPEC_TO_VIDEO_ENV` が `development` または `production` に設定されていること |
| 資格情報 | 本番環境で、使用するモデルに対応する環境変数が設定されていること |
| 上限 | 設計書の `cost_policy.retry_limit` と `cost_policy.hard_cap` が確定していること |
| ライセンス | 6 節の判定を満たすこと |

## 2. リトライ上限とハードキャップ

**素材単位のリトライ上限**と**課金上限**は別に管理します。片方だけでは暴走を止められません。

課金上限は2種類あり、併用できます。先に到達した方で停止します。

| 種類 | 効き方 |
|---|---|
| 全体の上限（`hard_cap`） | 全生成の合計に効きます。到達すると**すべての生成**を停止します |
| 対象ごとの上限（`hard_cap_by_kind`） | クリップ・起点画像・図解の別に効きます。到達した対象**だけ**を停止し、他の対象は続けます。`null` は上限を設けないことを表します |

対象ごとに単価が大きく異なる場合、全体の上限だけでは意図した配分になりません。単価の高い対象（クリップ）の枠を、単価の低い対象（画像）のリテイクが削るためです。

- リトライ上限に達した素材は保留とし、他の素材の生成を続けたうえで停止します。保留した素材は台帳に残します
- ハードキャップに達した場合、進行中の素材を含めてすべての生成を停止し、台帳と課金記録を確定します
- どちらの停止も、再開時は差分のみを対象とします。採用済みの素材は再生成しません

生成呼び出しは `scripts/generate_asset` を唯一の窓口とします。**他の経路から生成 API を呼び出しません。**

## 3. 課金ログ

`out/cost_log.json` に記録します。

| 項目 | 内容 |
|---|---|
| material_id | 対象素材です |
| operation | 生成の種別（起点画像・クリップ・図解）です |
| model_name | 使用したモデルです |
| generation_count | 当該素材に対する累計の生成回数です |
| estimated_cost | 見積もり課金額です |
| render_count | レンダリング回数です |
| stopped_by | 停止した理由（リトライ上限・ハードキャップ）です |

レンダリングも課金の対象に含めます。レンダ単位課金の条件下では、検証の反復がそのまま課金になります。

### 見積もりの求め方

```
クリップ単価 × 動画素材の総尺 × リテイク係数
  + 静止画単価 × 点数 × リテイク係数
```

構図と被写体のリテイクは起点画像の段階で行い、動画生成の失敗課金を抑えます。

## 4. 資格情報

- 利用者の環境変数から読みます。本文・参照ファイル・スクリプト・アセットに直書きしません
- 記載してよいのは**環境変数名のみ**です。値およびその一部を、ログ・台帳・レポート・エラー出力に残しません
- エラー出力に値が含まれた場合は、伏せて記録します
- ローカル TTS はネットワーク通信と資格情報を要しません。モデルと音声データは事前導入を前提とし、実行中に取得しません

## 5. モデルの選定

- 使用するのは gemini / nano banana / veo の範囲です
- **実行のたびに利用可能なモデルと単価を調べ、要件を満たす最安値を選びます**
- 単価の調査 → 見積もりの提示 → 承認 → 実行、の順で進めます。承認を得ずに生成を開始しません
- モデル・解像度・尺を引き上げる場合は、その都度確認を取ります
- モデル名・エンドポイント・許容クリップ長は、動画設計書の「使用モデル」表と実行環境から取得します。本ファイルにも埋め込みません
- 実際に使用したモデルと確認日は `docs/references.md` に記録します

## 6. ライセンス判定

Remotion は組織規模により利用条件が変わります。P2 で次を確認します。

- 営利目的かつ4人以上の組織は Company License が必要です
- Automators 相当の条件ではレンダ単位の課金になります
- 条件を満たさない場合は停止し、代替フレームワークへの切り替えを提示します

判定に用いた条件と確認日は `docs/references.md` に記録します。
