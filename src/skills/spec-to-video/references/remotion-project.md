# Remotion プロジェクトの構成と出力

工程 P11（プロジェクト同期）と P12（レンダリング）で読み込みます。

## 目次

1. プロジェクト構成
2. 実装制約
3. カット単位の同期
4. 遷移の実装方針
5. 出力規格の設定

---

## 1. プロジェクト構成

- コンポジションはシーン単位で定義し、シーン内をカット単位で分割します
- 素材の参照先は素材台帳（`data/clips.json`）の `file_path` です。台帳を経由せずにファイルを直接参照しません
- 採用済み（`adopted` が真）の素材のみを合成に用います
- 字幕とオーバーレイは、素材とは別の層として重ねます。素材そのものへ焼き込みません

## 2. 実装制約

**描画はフレーム番号に依存する純粋関数として実装します。** 同じフレーム番号に対しては常に同じ結果を返す必要があります。

- 乱数・現在時刻・外部通信を描画の中で使いません。ゆらぎが必要な場合は、フレーム番号から決定的に導出します
- 前のフレームの状態を持ち越しません
- この制約が守られていないと、レンダリングのたびに結果が変わり、再レンダリングでの検証が成立しません

## 3. カット単位の同期

- 各カットの音声（`cuts[].audio_path`）を、そのカットの区間に配置します
- アニメーションの区切りはカット境界に合わせます
- カットの生成尺がシーン尺を超える場合、**超過分は合成側のトリムで吸収します**。素材を作り直しません
- カット数は設計書の指定に一致させます。合成の都合で増減させません

## 4. 遷移の実装方針

- 遷移はカット境界にのみ置きます
- 遷移区間で輝度が急激に変化する実装を避けます。光感受性の検証で不適合となる主要因です
- 遷移の重なり時間は設定ファイルで定めます

## 5. 出力規格の設定

解像度・フレームレート・コーデック・音声形式は、動画設計書の `output_spec` から設定します。既定値で補完しません。

- `output_spec` が確定していない場合、P12 は実行せずに停止します
- 出力先は `out/final.mp4` です
- レンダリング回数は `out/cost_log.json` の `render_count` に計上します
