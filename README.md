# spec-to-video-pipeline

動画設計書から mp4 を生成するエージェントスキル `spec-to-video` の開発リポジトリです。

## このスキルでできること

動画設計書（シーン構成・字幕・尺・使用モデルを含む Markdown）を渡すと、次の工程を順に実行します。

1. 設計書を読み取り、必須項目を確認します
2. ナレーションをカット単位で合成し、実尺を計測します
3. 字幕を生成し、読みやすさを検査します
4. 素材（起点画像・クリップ・図解）を生成します
5. Remotion で合成し、mp4 を書き出します
6. 明滅や出力規格などを機械で検証し、人間の審査へ回します

課金を伴う工程の前には承認の確認が入ります。確認に答えるまで、素材の生成もレンダリングも始まりません。

## 入手と設置

1. [Releases](https://github.com/rictaworks/spec-to-video-pipeline/releases) を開きます
2. 最新のリリースに添付されている `spec-to-video-<バージョン>.skill` をダウンロードします
3. ファイルを展開し、中身を次の場所へ置きます

```
~/.claude/skills/spec-to-video/
```

展開後の直下に `SKILL.md` があれば設置は完了です。

## 使い方

動画設計書のパスを添えて、動画の生成を依頼します。

```
docs/video-spec.md の設計書で動画を作ってください
```

設計書に必須項目が足りない場合は、不足している項目を挙げて止まります。推測で補われることはありません。

## 出力されるもの

| ファイル | 内容 |
|---|---|
| `out/final.mp4` | 設計書の出力規格に合わせた本編です |
| `out/subtitles.srt` | 字幕ファイルです |
| `out/frame_analysis.json` | 明滅・不連続フレームなどの検出結果です |
| `out/cost_log.json` | 生成回数・レンダリング回数・課金額の記録です |
| `out/report.md` | 実行レポートです |

## 必要なもの

| 対象 | 内容 |
|---|---|
| Node.js | 22 以上 |
| 音声合成 | ローカルの合成エンジンと音声データを事前に導入してください。既定の話者は四国めたん（ノーマル）です |
| 生成 API の資格情報 | 素材を生成する場合に必要です。環境変数で渡します |
| 実行環境の指定 | 環境変数 `SPEC_TO_VIDEO_ENV` に `development` または `production` を設定します |

`development` を指定した場合、生成 API と音声合成は呼ばれず、動作確認用の代替へ切り替わります。課金は発生しません。

## バージョン

`メジャー2桁.マイナー2桁.デバッグ2桁` の形式です。初期値は `01.01.00` です。

| 桁 | 上がる条件 |
|---|---|
| メジャー | 入出力の形式が変わる、工程が削られるなど、これまでの使い方が通らなくなる変更 |
| マイナー | 使う場面の判定や、工程の分かれ方が変わる変更 |
| デバッグ | 参照情報の更新と不具合の修正 |

## 開発

| コマンド | 内容 |
|---|---|
| `npm ci` | 依存関係を導入します |
| `npm test` | テストを実行します |
| `npm run typecheck` | 型検査を実行します |
| `node scripts/build-skill-package.js <バージョン>` | 配布物を組み立てます |

仕様は `requirements.md` が正です。開発の進め方は `CLAUDE.md` に記載しています。
